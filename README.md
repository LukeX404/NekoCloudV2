# ☁️ NekoCloud V2 - Hospedagem de Servidores Minecraft

Landing page moderna de alta performance para a **NekoCloud**, reconstruída do zero utilizando **Next.js 16 (App Router)**, **React 19**, **TypeScript** e **Tailwind CSS**.

---

## 🚀 Principais Novidades & Recursos

- ⚡ **Next.js Recente & React 19**: Arquitetura moderna, fluida e otimizada para SEO.
- 🎨 **Tema Claro & Tema Noturno com Azul**: Suporte nativo para tema Branco com Azul e Noturno (Deep Navy com Azul Neon) com alternador em tempo real e persistência no `localStorage`.
- 📱 **Totalmente Responsivo**: Design mobile-first adaptado com menu drawer e botões touch-friendly.
- 🇧🇷 / 🇨🇦 **Seletor de Localização**: Brasil (São Paulo - ping 10~25ms) e Canadá (BHS - ping 120~150ms).
- 📶 **Teste de Latência & Cópia de IP em 1 Clique**: Ferramenta interativa para jogadores testarem a conexão antes de contratar.
- 💎 **Planos Completos**: Madeira, Ferro, Redstone, Ouro, Diamante e Netherita com especificações de hardware (Ryzen 9 7950X, NVMe Gen4, Anti-DDoS 228 Tbps Cloudflare).
- 💬 **Checkout Direto & Sem Fricção**: Contratação ágil via WhatsApp ou Discord sem necessidade de login.

---

## 🛠️ Como Executar

Instale as dependências e inicie o servidor local:

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
